Privacy Policy

Fab Shop Tycoon · last updated 16 September 2026

Fab Shop Tycoon collects no personal data. There are no accounts, no analytics, no advertising, no trackers, and no third-party SDKs. Nothing you do in the game is transmitted anywhere.

What the game stores

Your progress — cash, shop level, reputation, machine upgrades, jobs in flight — is saved in your device's local browser storage (localStorage) so the game can resume where you left off. This data:

  • stays on the device it was created on;
  • is never uploaded, shared, or sold;
  • is not readable by us or by anyone else;
  • is deleted when you uninstall the app, clear site data, or use the in-game Reset shop button.

Network use

The mobile app runs entirely from files bundled inside it and does not need a network connection to play. The web version downloads the game files from its host and then works offline. No gameplay data is sent over the network in either case.

Permissions

The app requests no device permissions: no camera, microphone, location, contacts, photos, or storage access. The Android build declares the standard internet permission required by its web view runtime, but the game makes no network requests of its own.

Children

The game is suitable for all ages and does not knowingly collect information from anyone, including children under 13. Because no data is collected at all, none can be collected from a child.

Changes

If this policy ever changes, the revised version will be posted at this address with an updated date. Any change that affects what data is handled would ship alongside an app update and its release notes.
